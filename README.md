# Moringa School Software Engineering Curriculum Hub

A full-stack application built to track skills, test APIs, visualize database schemas, and practice standard developer workflows based on the Moringa School SE curriculum.

## Tech Stack
- **Frontend:** React (Vite), Tailwind CSS, Lucide Icons
- **Backend:** Python, Flask, Flask-SQLAlchemy, Flask-CORS
- **Database:** SQLite / PostgreSQL
