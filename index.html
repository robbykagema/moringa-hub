Git & Repository Deployment Quickstart

# 1. Initialize repository

$ git init

$ git add .

$ git commit -m "Initial commit: Moringa Full Stack Portfolio Hub"

# 2. Link to your GitHub Repository

$ git branch -M main

$ git remote add origin https://github.com/YOUR_GITHUB_USERNAME/moringa-hub.git

$ git push -u origin main
